Keyboard shortcut

A shortcut hint displays a command using the reader’s platform conventions. The application owns the action and its keyboard listener.

Search

Duplicate

Close

Use it

import '@0001-labs/app/keyboard-shortcut';

<ds-kbd shortcut="mod+k"></ds-kbd>
<ds-kbd shortcut="escape" plain></ds-kbd>
<ds-kbd>Fn</ds-kbd>

Platforms

Apple

Other

shortcut
The command, written once: mod+k, mod+shift+d or escape.
plain
Muted text without a fill, for use beside an action.
platform
Optional apple or other override. By default, follows the reader’s device.

React

import '@0001-labs/app/keyboard-shortcut';
import { Kbd } from '@0001-labs/app/react/keyboard-shortcut';

<Kbd shortcut="mod+k" />

Spacing handle

Adjust a spacing value by dragging or using the arrow keys. The application owns preview, commit and undo.

Use it

import '@0001-labs/app/spacing-handle';

handle.options = {
  value: 20, min: 0, max: 100, step: 10,
  onPreview: value => preview(value),
  onCommit: value => save(value)
};

Loading indicator

Automatic pending-state feedback, with an accessible status label. Use a bar for a page or a spinner beside a control.

Use it

import '@0001-labs/app/loading';

<ds-loading label="Loading document"></ds-loading>
<ds-loading variant="spinner"></ds-loading>
