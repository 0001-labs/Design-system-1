---
title: Installation
description: Start with HTML and CSS, then add interactive components when needed.
---

For ordinary HTML, follow [Use with HTML](/start-here/quick-start/). It uses the current public stylesheet and fonts, with no framework or build step. [Download a complete example](/start-here/examples/) to begin.

For interactive components, see the [component catalogue](/2-core/overview/#component-overview) and each component's import/API documentation. The npm alpha package is another distribution channel, but it may lag the current documentation release; check that a component exists in the installed version. CSS-only pages do not need that package or its JavaScript bundle.
