## Shops and apps

- [Shop](/examples/shop/) — a photo-led collection with filters and a shopping bag.
- [Planning app](/examples/planner/) — project navigation, searchable items and a visual brief.
- [Finance app](/examples/finance/) — account balances, cash flow and transactions.
- [Product showcase](/examples/product/) — a product story, large photographs and a package choice.

These are working local examples with fictional content. Their components, colours, type and spacing come from the current DS1 source; example CSS only arranges the pieces.

## HTML examples

Each HTML example is a complete HTML document. Open it to try the page, or download the file and edit it in any text editor. No framework, package install or build step is needed.

The files use the same native stylesheet as Design system 1's library workspace, served from this site's canonical source. The companion font stylesheet configures the supplied GT America and Iosevka fonts; the native stylesheet itself imports no fonts. These are online dependencies, not embedded files.

## What you download

One authored HTML file, including any small example-specific script. The article, report and reference have no JavaScript. The form's script only shows local feedback and prevents submission; it has no backend.

The CSS and fonts load over the internet. To work offline, save both CSS files and the fonts the font stylesheet references, then change the paths in your copy. A file opened with no connection falls back to browser styling if those resources are unavailable.

## More behavior

For custom charts, menus, sidebars and other interactive controls, use the [Web Component examples](/2-core/overview/#component-overview). Those components need JavaScript; a stylesheet alone does not implement them. Start with the [overview](/start-here/overview/) for the full map, or [My libraries](/libraries/) for saved stylesheets.
