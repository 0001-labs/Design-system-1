## Page layouts

The six page compositions, filled with working controls. Use **Show layers** to see how the pieces fit, or **Code** to copy their source.

### Sidebar

An app with places to go: navigation stays on the left while the work changes on the right.

<LayoutExample layout="sidebar" />

### List and detail

Many things of one kind: pick one from the list and read it in full beside it. The list column is 16 squares, wide enough for a name and a date.

<LayoutExample layout="split" />

### Inspector

Making something: pages on the left, the work in the middle, its settings on the right. Below 48 squares of width the settings move under the work.

<LayoutExample layout="inspector" />

### Column

Something read or filled in from top to bottom: settings, an article, a long form. The column is 32 squares wide and sits in the middle, on a whole square.

<LayoutExample layout="column" />

### Centred

One task and nothing else on the screen: signing in, confirming, a single question. The column is 16 squares and sits in the middle of the height too, on a whole square.

<LayoutExample layout="centered" />

### Tiles

An overview of many numbers at once. Each tile is 12 squares wide and the row fills with as many as fit; `data-tile="wide"` takes two, `data-tile="full"` the whole row.

## HTML examples

Each HTML example is a complete HTML document. Open it to try the page, or download the file and edit it in any text editor. No framework, package install or build step is needed.

The files load the Design system 1 stylesheet and bundled Lit module from this site, then use `ds-*` elements alongside semantic HTML. Fonts load with the stylesheet. These are online dependencies.

## What you download

One authored HTML file, including any example-specific script. The Lit module registers the components. The form shows local feedback and prevents submission; it has no backend.

To work offline, serve a local copy of the library bundle, its chunks, CSS and fonts, then update the URLs in your HTML.

For more components, see the [component examples](/2-core/overview/#component-overview), or start with [Use with HTML](/start-here/quick-start/).
