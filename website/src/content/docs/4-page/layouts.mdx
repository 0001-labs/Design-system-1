A page is built in three layers. **Core** pieces do one thing each: a button, a text, a badge. **Units** put core pieces together: a row, a list, a sidebar, a form. The **Page** decides where the units stand. `<ds-page>` is that last layer: pick a layout and drop your units into its areas.

Each example below is a real page with sample content. Press **Show layers** to colour it by layer: core pieces in green, units in blue, the page's areas in pink. Point at anything to read what it is and what it sits in. **Phone** shows how the layout stacks on a narrow screen.

## Areas

Every layout has the same five areas, so content moves between layouts without being rewritten. An area with nothing in it takes no room.

| Area | Put it there with | Holds |
| --- | --- | --- |
| Header | `slot="header"` | The page's title and its main actions, along the top of the main area. |
| Nav | `slot="nav"` | Navigation, or the list in List and detail. The leading column. |
| Main | No slot | The work itself. |
| Aside | `slot="aside"` | Properties or related things. Its own column in Inspector, under the main area elsewhere. |
| Footer | `slot="footer"` | Closing actions such as Save, along the bottom of the main area. |

## Widths

Every column is a whole number of squares. Between columns there are two squares, between areas down the page one, and one around the page.

| Layout | Leading column | Main | Trailing column |
| --- | --- | --- | --- |
| `sidebar` | 12 squares | The rest | — |
| `split` | 16 squares | The rest | — |
| `inspector` | 12 squares | The rest | 12 squares |
| `column` | — | 32 squares, centred | — |
| `centered` | — | 16 squares, centred both ways | — |
| `tiles` | — | 12-square tiles | — |

Below 30 squares of width every layout becomes one column, navigation first. The layout follows the width of its own container, not the window, so a page inside a panel stacks when the panel is narrow.

## Attributes

| Attribute | Default | What it does |
| --- | --- | --- |
| `layout` | `sidebar` | `sidebar`, `split`, `inspector`, `column`, `centered` or `tiles`. |
| `divided` | false | Draws a hairline between the columns. |
| `fill` | false | Takes its container's full height; each column scrolls on its own. |
| `view` | false | Outlines each area and names it, for inspection. |

Change a width with `--ds-page-nav`, `--ds-page-aside`, `--ds-page-measure` or `--ds-page-tile` on the element. Keep them whole squares: `calc(16 * var(--ds-unit))`.
