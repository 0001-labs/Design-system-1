## When to use it

Use a tooltip to clarify a compact control. Keep essential instructions visible on the page: someone on a touch screen may never hover. Put a focusable button or link inside the wrapper so keyboard users can reveal the label too.

## Attributes

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `text` | string | Empty | A translation key or literal label. |
| `default-value` | string | Empty | Fallback when the key has no translation. |

## Behaviour

The label appears above the trigger on hover or focus and disappears on mouse leave or focus leaving the trigger. `position` is not a supported attribute: the component always places its label above the trigger.

## Many tooltips on one page

For a collection of controls, the shared tooltip module also supports `data-tooltip="Save changes"`. Import `DS1/0-face/tooltips.ts` once; it draws a shared label for those elements, including marked elements inside a component's open shadow root, as the [Sidebar](/3-unit/sidebar/) marks its cut-short labels. Mark only what the label adds to: a cut-short or icon-only control, never every row.
