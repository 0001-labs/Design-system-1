`ds-checkbox` draws a one-square checkbox around a native input. `ds-switch`
draws a 32 × 16px switch around a native button: two control heights wide,
with a 12px thumb, 2px inset and 16px travel. All switch measures follow the
shared scale. The checkbox stays one square high. Both follow the shared
palette and keep their focus ring visible.

```html
<label><ds-checkbox><input type="checkbox" name="updates" /></ds-checkbox> Updates</label>
<ds-switch><button type="button" role="switch" aria-checked="false" aria-label="Sharing"></button></ds-switch>
```

The native control keeps the label, ref, disabled fieldset behavior, events and
form owner. Checkbox also keeps required validation, FormData and native reset;
its `indeterminate` property draws the mixed state. Switch uses native button
activation for both Space and Enter and never submits a form. Product state
sets its `aria-checked` value after a change is accepted.

React products import `Checkbox` and `Switch` from `DS1/react/choice`. Register
the Lit elements in the browser before hydration; the adapters are safe to render
on the server. Pass standard input props to Checkbox. Switch takes `checked` and
`onCheckedChange`; canceling its `onClick` prevents the change request. Disabled
and busy state are distinct: `aria-busy` announces work, while `disabled` blocks
activation when the product requires it. Put accessible labels on the native
control, including `aria-label` for switches without visible text.

```tsx
<Checkbox name="updates" checked={updates} onChange={e => setUpdates(e.currentTarget.checked)} />
<Switch aria-label="Sharing" checked={sharing} onCheckedChange={setSharing} disabled={saving} />
```

Product wrapper classes arrange the control in a row; the shared component owns
the track, thumb, checkbox mark, colors, focus and disabled face. Do not retain
product CSS for those parts. Verify actual keyboard activation, labels, native
forms and reset after migration, on light and dark paper and at phone width.

## Rounded

`rounded` makes the switch a pill: a white round thumb on a darker green when it is on, grey when it is off, whatever the page's accent. It is the same control with the same measures, state and keyboard; a page without Lit writes `ds-switch ds-switch--rounded` on the native button.

<ComponentExample example="toggle" />

```html
<ds-switch rounded><button type="button" role="switch" aria-label="Notifications" aria-checked="true"></button></ds-switch>
```
