## Available settings

| `type` | Values |
| --- | --- |
| `theme` | Light and dark. |
| `language` | The configured languages. Prefer `ds-language` for a language picker. |
| `accent-color` | The system’s eight accent colours. |
| `page-style` | Note and page. |
| `notes-style-medium` | Default, big and gallery. |
| `icon-only` | Note and page icons. |

## Your own values

Leave out `type` and give `values` instead, as a JSON array in the attribute or an array property. The cycle shows each value as its label, starts on `value` when that is one of them and otherwise on the first, and on each click moves to the next and emits a `change` event whose `detail.value` is the new one. Setting `value` from a script moves the cycle without an event. Nothing is remembered. The [Chart](/2-core/chart/) page uses one to step through the chart types.

```html
<ds-cycle values='["Line","Area","Bars"]'></ds-cycle>
```

## Behaviour

These settings use the shared preferences module. Clicking a theme or accent cycle changes that setting for the document and remembers it in the browser. The preview above contains its own document, so trying a theme does not repaint the surrounding example list.

Set `disabled` to prevent cycling. Each setting emits the corresponding window event, such as `theme-changed`, `language-changed` or `accent-color-changed`.

Use `primary` or `secondary` to choose the shared button face. The older `variant`
attribute remains supported. Language and theme cycles default to secondary;
other built-in settings default to primary. Disabled fieldsets also disable a
cycle. A language cycle with only one available language does not write or emit
a redundant change.

Products retaining existing browser storage names set `window.DS_ONE_PREFERENCES`
before importing these modules. `storageKey` names the merged preference object
and `themeStorageKey` names the saved light/dark value. Defaults remain
`ds-one:preferences` and `ds-one:theme`; the language runtime's `storageKey` is
configured separately through `configureI18n`.
