Toggle turns a setting on or off. Its rounded track holds a white circular thumb; green means on and grey means off.

## Use it

Use `<ds-toggle>` around a native button with `role="switch"`, an accessible label and `aria-checked="true"` or `"false"`. Set `disabled` on the button when the setting cannot change. Native button behavior provides keyboard activation with Space and Enter.

Your application owns the state and saves it. Update `aria-checked` after accepting a change; the control does not write to storage or submit a form by itself. Use `type="button"` inside forms.

The control is 32 × 16 pixels at base scale, with a 12-pixel circular thumb and 2-pixel inset. Dimensions follow the shared component scale. The on track uses `--ds-switch-track-on`; the thumb uses `--ds-white`.

Import `DS1/2-core/ds-toggle` from your source copy, or select `toggle` in the Sync 1 components export. The package entry also registers it.

Existing `<ds-switch>` integrations remain compatible. Use `<ds-toggle>` for the rounded Toggle shown here.

A page without Lit draws this rounded switch with `ds-switch ds-switch--rounded` on the same native button. The `ds-toggle` class is something else: a toggle button that stays pressed, `<button aria-pressed>`. [Native controls](/1-root/native-controls/#toggle-button) says when to use a switch, a toggle button or a segmented control.
