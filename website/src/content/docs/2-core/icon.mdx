## Find an icon

The [icon collection](/2-core/icon/collection/) shows every interface icon by name; click one to download its SVG.

## Attributes

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `type` | string | Empty | File name from `DS1/x-icon/`, without `.svg`. |
| `variant` | `glyph`, `primary`, `secondary` | `glyph` | Plain drawing or a background treatment. |

Use `type="check"`, not `name="check"`. There is no `size` attribute. The drawing follows the system’s `--sf` scale. Use `--icon-color` when a control needs a different ink.

## Accessible labels

A decorative icon beside text can have `aria-hidden="true"`. Give an icon-only button an accessible name on its actual button. A tooltip supplements that name; it is not a replacement for it.

## Without Lit

A page without Lit masks the icon file in the text colour with the `ds-icon` class, at the same sizes: `<span class="ds-icon" style="--ds-icon: url(icons/close.svg)"></span>`. See [Native controls](/1-root/native-controls/#icon).

## Source and additions

The source files live in `DS1/x-icon/`. Add missing drawings to that library first, then generate the runtime map and public collection. Products carry the icons they use as local files.
