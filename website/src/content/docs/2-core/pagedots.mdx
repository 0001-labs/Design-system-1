Page dots stand under a row of slides or a set of pages: one dot each, one square apart, the current one filled and half again as large. The dots before it are filled in the muted colour, the next one in the text colour, and the rest are rings, so the row reads as how far you have come and where you go next. Each dot is a button that takes you to its slide.

A [Carousel](/3-unit/carousel/) draws its own dots; use `ds-pagedots` on its own for pages that move some other way.

## Use it

```html
<ds-pagedots count="5" active="1"></ds-pagedots>
```

```js
dots.addEventListener("select", event => {
  showPage(event.detail.index);
});
```

Pressing a dot fires `select` with `{ index, previous }`; unless a listener cancels it, the dot becomes current. Cancel it when the page decides, and set `active` once it has moved. Setting `active` fires nothing.

`end` draws the last dot as a ring in the text colour, an end marker, unless it is current: the way on to something past the slides, such as a set of templates after a tour.

## Keyboard

The dots are a group named "Slides", each a button named "Slide 2", the current one marked `aria-current`. Only the current dot is in the tab order. The arrow keys move to the dot before or after and pick it (left and right follow the reading direction), Home and End go to the first and the last, and focus follows. Enter and Space press the focused dot, as any button.

## API

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `count` | number | `3` | How many dots. |
| `active` | number | `0` | The current dot, from 0. |
| `end` | boolean | `false` | Draw the last dot as an end marker. |
| `label` | string | The shared word "Slides" | The group's name: a translation key, or words with `literal`. |
| `dot-label` | string | The shared words' "Slide &#123;index&#125;" | Each dot's name, `{index}` its number from 1, such as "Page &#123;index&#125;". |
| `literal` | boolean | `false` | Show `label` and `dot-label` as written, never looked up. |

| Event | Detail | What it means |
| --- | --- | --- |
| `select` | `{ index, previous }` | A person picked a dot. Cancelable. |

## Measures

Each dot is a button one square wide and one square high, so the row is one square high and as many squares wide as there are dots. The dot itself is 4px, scaled with the surface, and the current one is drawn half again as large; only its size moves, and not at all when the reader asks for reduced motion. The focus ring stands inside the dot's square.

| Token | Default | Dots |
| --- | --- | --- |
| `--ds-pagedots-past` | `--ds-text-color-muted` | Filled, before the current one |
| `--ds-pagedots-current` | `--ds-text-color` | Filled and larger |
| `--ds-pagedots-next` | `--ds-text-color` | Filled, the one after |
| `--ds-pagedots-future` | `--ds-text-color-muted` | A ring |
| `--ds-pagedots-end` | `--ds-text-color` | A ring, the end marker |

Set them on the dots or on any element around them, for example to draw the current dot in an accent.

## Without JavaScript

A page without Lit writes an empty `.ds-pagedots` and lets the carousel script draw the dots, or draws them itself with the same classes from `carousel.css`, which `controls.css` imports:

```html
<div class="ds-pagedots" role="group" aria-label="Slides">
  <button class="ds-pagedots__dot" type="button" data-state="past" aria-label="Slide 1" tabindex="-1"></button>
  <button class="ds-pagedots__dot" type="button" data-state="current" aria-current="true" aria-label="Slide 2"></button>
  <button class="ds-pagedots__dot" type="button" data-state="next" aria-label="Slide 3" tabindex="-1"></button>
</div>
```

`data-state` is `past`, `current`, `next`, `future` or `end`. `startPagedots(element, { count, current, end, onSelect })` from `0-face/carousel.ts` fills and keeps them, with the keyboard. See [Carousel](/3-unit/carousel/#without-javascript).
