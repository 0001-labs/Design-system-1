---
title: Split compatibility
description: The existing split name remains compatible with Button split mode.
---

Split controls are now a [mode of Button](/2-core/button/#split-mode). Use `<ds-button split>` in HTML and `<Button split>` from `react/button` in React. Choices, repeated actions, icons, controlled selection and disabled segments are documented there.

Existing `<ds-split>`, the React `Split` adapter and Sync 1's `split` selection continue to use the same implementation. Their options, segments, values, events, focus and disabled-fieldset behavior are preserved. No split-pane or page-layout component is changed.
