---
title: Select
description: Native choices with the shared field face.
---

`ds-select` draws a native select field on the grid. It is one square high and
eight wide by default; layout can set the host width. Size and multiple-selection
lists use one square per visible row, four rows by default for `multiple`.

```html
<label>Project
  <ds-select><select name="project" required>
    <option value="">Choose a project</option>
    <option value="alpha">Alpha</option>
  </select></ds-select>
</label>
```

The native select owns labels, options, option groups, selection, keyboard
navigation, the platform picker, validation, FormData, disabled fieldsets and
reset. DS1 owns the field face, arrow, scale, focus and disabled appearance.
There is no second hidden input and no replacement popup or keyboard handler.

React products import `Select` from `DS1/react/choice`. Standard native select
props, children and the native ref pass through. `className`, `style` and `hidden`
also place the host in the product layout. The adapter can render on the server;
register `ds-select` in the browser before hydrating.

```tsx
<Select name="project" value={project} onChange={e => setProject(e.currentTarget.value)}>
  <option value="alpha">Alpha</option>
  <option value="beta">Beta</option>
</Select>
```

Remove product select appearance CSS and duplicate arrows when migrating.
Keep data and persistence callbacks in the product. Verify required validation,
controlled changes, labels, reset, keyboard choices and disabled state on light
and dark paper, with the product scale and at phone width.

## Compact and colour choices

Use `fit` to size a single picker to its native options. `chip` uses the shared
16px control height and quiet button face; `primary` gives a chip the accent.
Widths and type follow the containing surface scale. Lists with `multiple` or
more than one visible row keep their normal field face.

```html
<ds-select fit chip primary><select aria-label="Sort direction">
  <option value="asc">Ascending</option><option value="desc">Descending</option>
</select></ds-select>
```

For a colour category picker, pass `swatch` a CSS colour. DS1 composes its own
`ds-swatch` inside a one-square control; the native select still receives
keyboard focus and opens the platform picker. Supply an accessible name and
keep the colour/category mapping and selected value in the product.

```tsx
<Select swatch={categoryColour} aria-label="Category" value={category}
  onChange={event => setCategory(event.currentTarget.value)}>
  <option value="work">Work</option>
  <option value="personal">Personal</option>
</Select>
```

The React adapter also accepts `fit`, `chip` and `primary`. These visual
properties go on the shared host; all native select properties stay on the
select. No product overlay, hidden select styles or duplicate swatch face is
needed.
