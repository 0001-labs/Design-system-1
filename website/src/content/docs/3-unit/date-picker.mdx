A date picker is a field one control high with the calendar icon at its start and the down arrow at its end. Pressing it opens a panel half a square below, on the menu's frame: the first and last day written out where they can be typed, the [compact month](/3-unit/calendar/#compact) one square a day, an **Include time** switch and **Clear**.

It always collects a range. The first day pressed starts it, and the value is that day; the second day pressed, before or after, ends it and closes the panel. Pressing the same day twice, or leaving after the first press, keeps one day. Opening the panel again on a whole range, the next press starts a new one.

## Use it

```html
<form>
  <ds-date-picker name="when" label="When" literal min="2026-10-01"></ds-date-picker>
</form>
```

```js
picker.addEventListener("change", event => {
  console.log(event.detail.value); // "2026-10-21", "2026-10-21/2026-10-24", "2026-10-21T09:00/2026-10-21T10:00", or "" when cleared
});
```

The value is ISO 8601: a day, a day with its time, or two of them joined by a slash, which is also what a form sends. A value with a time turns Include time on; `time` sets it from the page, and `no-options` leaves the switch out.

| Value | Face |
| --- | --- |
| `2026-10-21` | Oct 21, 2026 |
| `2026-10-21/2026-10-24` | Oct 21 – 24, 2026 |
| `2026-10-21T09:00/2026-10-21T10:00` | Oct 21, 2026, 9:00 – 10:00 AM |

The face writes the value in the current language, a range as the language writes one. `length` writes a day `short`, `medium` (the default) or `long`; before a day is chosen the face reads `placeholder`, the shared words "Choose a date" by default, in the title grey.

## The panel

| Measure | Size |
| --- | --- |
| The field | The select's face: one control high at the foot of its square, ten squares wide (`--ds-date-picker-width`). |
| The days to type | A field one control high on its own square for the first day and one for the last; with times on, each day's time on the square below it. One square spare after them. |
| The month | One square a day, seven squares wide: the month with its chevrons, the weekdays in a letter, six weeks with the neighbouring months' days in the title grey. |
| The marks | 18 × 18px: the chosen days are squares with 4px corners in Sharp blue, the days between on a band of it, today a red disc. |
| Include time, Clear | One square each, the switch at the end, set off by one-square separators with a line through them. |
| The frame | A 1px line with half a square inside it, no shadow: eight squares wide. |
| Its place | Half a square below the field, or above it when there is more room there, kept on screen. |

Turning times on gives the first day 9:00 and the last 10:00, which the time fields change; with times on, the panel stays open after the second press so they can be set.

A typed day is read when the person presses Enter or leaves the field: `2026-10-21`, or a date the browser can read such as "Oct 21, 2026". Anything else puts the field back as it was.

`required` leaves Clear out and tells the form a value is missing. `min` and `max` limit the days. A form's reset puts back the value the field started with.

## Accessibility

- The field is a button with `aria-haspopup="dialog"` and `aria-expanded`, named by `label` and the value.
- Enter, Space or the down arrow opens the panel with the focus on the first chosen day (or today); a click opens it and leaves the focus on the field.
- In the month, the arrow keys, Home, End, Page Up and Page Down move as in the [calendar](/3-unit/calendar/#accessibility); Enter or Space presses a day. The month is `aria-multiselectable` and every day of the range `aria-selected`.
- The typed fields and times are named by the label and which end they are; the switch is `role="switch"`.
- Escape, a press outside, or the focus leaving closes the panel, and the focus goes back to the field.

## API

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `value` | string | `""` | A day or a range, with or without times, in ISO 8601. |
| `name` | string | — | The form field's name. |
| `label` | string | The shared word "Date" | The field's name; `literal` shows it as written. |
| `placeholder` | string | "Choose a date" | The words before a day is chosen. |
| `length` | string | `medium` | How a day is written. |
| `time` | boolean | `false` | Choose a time with each day (Include time). |
| `no-options` | boolean | `false` | Leave the Include time switch out. |
| `min`, `max` | string | — | The days a person may choose. |
| `week-start` | string | The language's | The week's first day. |
| `today` | string | The reader's today | The day drawn as today. |
| `required` | boolean | `false` | A form needs a value. |
| `disabled` | boolean | `false` | The field cannot be opened. |
| `open` | boolean | `false` | The panel is open. |

| Event | Detail | What it means |
| --- | --- | --- |
| `change`, `input` | `{ value, previous }` | A person changed the value. |
| `ds-date-picker-toggle` | `{ open }` | The panel opened or closed. |

| Method | What it does |
| --- | --- |
| `show()`, `hide()` | Opens or closes the panel. |

`readDateValue`, `writeDateValue` and `parseTypedDay` are exported for a page that reads or writes the value itself.

| Part | What it is |
| --- | --- |
| `trigger` | The field. |
| `popover` | The panel's frame. |
| `field` | A row of a day or a time to type. |
| `options`, `clear` | The switch and Clear. |
