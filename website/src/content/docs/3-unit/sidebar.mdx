The Sidebar is twelve squares wide. Each row is one square high, with half a square of indentation per level. Labels use regular text; counts and supporting information use small text. Disclosure arrows follow their labels. Selection fills the whole row with 2px corners, scaled with the surface.

## Data and behaviour

Set the `items` property to an array of visible rows. Each row has a unique `id` and a `label`; optional fields are `depth`, `href`, `expanded`, `current`, `disabled`, `meta`, and `action: { id, label }`. Omit `expanded` for a leaf. Collapsed children must be omitted from the array.

The application owns the hierarchy, filtering, selected destination and saved expansion state. The Unit owns the row layout, disclosure controls, focus and keyboard navigation. Supply a `label` for the navigation landmark and `empty` for its empty state. The `header` and `footer` slots hold optional search and supporting controls. When the host has a constrained height, only the navigation rows scroll; header and footer controls stay visible.

| Event | Detail | Application response |
| --- | --- | --- |
| `sidebar-activate` | `{ id }` | Cancel with `preventDefault()` to handle routing or guard unsaved changes. |
| `sidebar-toggle` | `{ id, expanded }` | Update the visible items if expansion is accepted. |
| `sidebar-action` | `{ id, action }` | Run the independent trailing action. |

Links retain their native destinations, context menus and modified clicks. Buttons support Enter and Space. Up and Down move between available rows; Home and End move to the first and last. Right expands a closed section or enters its children; Left collapses an open section or moves to its parent. Tab also reaches disclosure and trailing actions.

A label too long for its row ends in an ellipsis and shows in full in the shared [tooltip](/2-core/tooltip/) on hover or focus; a label that fits has none, and no row carries the browser's `title`. The Sidebar loads the tooltip module itself.

Call `focusItem(id)` after `updateComplete` to focus a row, or `scrollToCurrent()` to reveal the current destination. `--ds-sf` scales the width, rows, text, icons and indentation. A containing layout may set the host width to another whole number of squares.

The rows' fills and the current row's weight are the shared row tokens (`--ds-row-fill-hover`, `--ds-row-fill-current`, `--ds-row-current-weight`), so a [navigation row](/3-unit/row/#navigation-rows) and a [tree](/3-unit/tree/)'s selected row look the same. For a chooser of nested things inside a page, with one Tab stop and a selection, use the [Tree](/3-unit/tree/).
